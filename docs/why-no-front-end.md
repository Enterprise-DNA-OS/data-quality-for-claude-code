# Why the desk has no front end

The weekly work is a small set of records and decisions: define checks, run an extract, investigate failures, assign corrections and keep evidence. A coding agent can operate those jobs through one tested CLI.

Read-only HTML gives the team the week, current failures and review paperwork. It has no edit buttons. Ask the agent to act and let it show the result in the conversation.

A screen would give a shared login, guided input, mobile access and live charts. This base provides none of those. CSV checking works locally after installation, but there is no offline mobile synchronisation, drag and drop, hosted scheduler or live warehouse monitoring. Choose and build those integrations around the business if they are required. The data model remains yours.
